🪨📄✂️ Steen Papier Schaar – Tutorial

Welkom bij de tutorial van ons project! Dit is een interactieve game gebouwd met HTML, CSS en JavaScript. Hieronder leggen we uit hoe het spel werkt en hoe het technisch in elkaar zit. En een link naar het spel zelf.

🔍 Hoe werkt het spel?

  • Jij kiest één van de drie opties: Steen, Papier of Schaar.
  • De computer kiest automatisch ook één van de drie opties.
  • Beide keuzes worden weergegeven bij hun “avatars”.
  • De winnaar wordt bepaald volgens de klassieke regels.
  • Score wordt live bijgehouden.

🛠️ Gebruikte technologieën

  • HTML – structuur van de gamepagina
  • CSS – styling en layout
  • JavaScript – logica, scores en interactiviteit
